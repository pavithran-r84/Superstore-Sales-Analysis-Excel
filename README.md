**Superstore Sales Analysis (Excel Project)**

This project presents an end-to-end analysis of a 550-record sample from the Superstore dataset using Microsoft Excel. The objective of the study was to understand key business patterns such as sales performance, profit behavior, discount impact, customer segmentation, and shipping trends. The project includes data cleaning, exploratory analysis, pivot-based visualizations, and the development of an interactive Excel dashboard.

**Project Summary**

The dataset was cleaned by removing duplicates, correcting inconsistent values, fixing date and numeric formats, and creating calculated fields such as Profit Margin and Order Year.
Exploratory analysis was performed using pivot tables to study trends across regions, categories, customer segments, shipping modes, and discount ranges.

An interactive dashboard was then built using pivot charts and slicers to help users quickly explore insights and understand performance trends across different dimensions.

**Workflow Overview**

The project follows a simple and structured four-phase workflow:
1. Data Collection – Imported the sample dataset into Excel
2. Data Cleaning – Removed duplicates, fixed formats, standardized categories
3. Exploratory Analysis – Studied trends using pivot tables and charts
4. Dashboard Creation – Built a visual dashboard for interactive analysis

**Key Insights**

1. The West region shows the highest sales and profit.
2. The Technology category contributes the strongest profit margins.
3. Discounts above 30% lead to a noticeable drop in profits.
4. The Consumer segment contributes nearly half of total revenue.
5. Standard Class shipping is most commonly used but slower.

**Business Recommendations**

1. Limit heavy discounting to avoid margin losses.
2. Focus more on promoting high-profit Technology products.
3. Strengthen marketing in the Central region to improve performance.
4. Offer incentives for faster shipping modes.
5. Build long-term customer engagement programs for the Consumer segment.
